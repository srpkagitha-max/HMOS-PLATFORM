# HMOS Changelog

## v2.1.1
- Shows the exact Firebase Authentication error code on the Super Admin login screen.
- Added messages for invalid credentials, missing user, disabled user, unauthorized domain, disabled Email/Password provider, invalid API key, and network errors.
- Changed the service worker to fetch JavaScript and Firebase configuration from the network first.
- Bumped the PWA cache so older login code is removed automatically.

## v2.1.0
- Super Admin Firebase Authentication and Firestore profile verification.
- Super Admin dashboard and institute creation foundation.
