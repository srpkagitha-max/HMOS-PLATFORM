# HMOS V4.0.0

## Performance & Stability Core — Phase 1
- Single runtime: app.js + firebase-service.js.
- Institute-scoped reads for residents, rooms, fees, payments, admissions, attendance, movements, complaints, approvals, notifications, audit logs, recycle bin and backups.
- Query safety limits to prevent accidental huge mobile downloads.
- New V4 cache and session namespaces.
- Network-first PWA navigation with controlled cache cleanup.
- Visible startup, offline and reconnect recovery messages.
